# 弹出菜单标题垂直对齐设计

## 目标

让“New shell”和“Insert command”弹出菜单顶部的分组标题在各自标题行中略微下移，避免文字视觉重心过于贴近菜单上缘。

## 范围

- 为两处标题行采用一致的垂直内边距：上 12px、下 6px。
- 保持标题文字样式、分隔线、菜单宽度、菜单项高度和交互行为不变。
- 不整体移动弹出菜单，也不增加菜单主体或命令条目的间距。

## 实现

- 将 Plus 菜单的 section header 从固定 28px 行调整为内容驱动的标题行，并应用统一内边距。
- 将命令选择器桌面菜单的标题项采用相同内边距；移动端对话框标题同步使用该内边距。
- 抽取或复用私有常量，确保后续菜单标题保持一致。

## 验证

- 运行现有命令选择器 widget 测试。
- 运行 Dart formatter 和静态分析，确认布局调整不引入代码问题。
