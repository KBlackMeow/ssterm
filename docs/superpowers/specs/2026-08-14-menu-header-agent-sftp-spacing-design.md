# 菜单标题对齐与边距设计

## 目标

参照 Agent 与 SFTP 面板的紧凑层级，让新 Shell 和插入命令菜单的分组标题与其内容、分隔线形成更协调的对齐关系，同时保留标题不贴近菜单上缘的视觉效果。

## 参考

- Agent 面板标题使用 12px 水平内边距及紧凑的 8px/4px 垂直节奏。
- SFTP 工具栏以较小的水平留白和 4px 间隔维持密度。

## 决策

- 菜单标题使用统一的 `EdgeInsets.fromLTRB(12, 10, 12, 6)`。
- 12px 左右内边距与 Agent 标题的内容起始线对齐。
- 10px/6px 垂直内边距保留向下的视觉重心，避免恢复为原先偏上的标题。
- 适用于 Plus 菜单的所有分组标题、桌面“Insert command”标题和移动端命令选择器标题。

## 非目标

- 不改菜单项、分隔线或弹出框宽度。
- 不修改 SFTP、Agent 面板自身的间距。

## 验证

- 命令选择器 widget 测试断言新的精确标题内边距。
- 运行格式化、静态分析和完整 Flutter 测试套件。
