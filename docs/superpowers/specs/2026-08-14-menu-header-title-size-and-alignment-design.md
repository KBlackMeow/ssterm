# 菜单标题字号与对齐设计

## 目标

使弹出菜单标题的首字母与菜单左、上边缘保持一致的 12px 间距，并提升标题层级，使其与 Agent 标题协调。

## 决策

- Plus 菜单和命令选择器的标题字号统一为 12px。
- 标题内边距统一为 `EdgeInsets.fromLTRB(12, 12, 12, 6)`。
- 桌面与移动端命令选择器保持相同的标题规格。

## 非目标

- 不改变菜单项、分隔线、宽度或点击行为。
- 不调整 Agent 或 SFTP 面板本身。

## 验证

- 回归测试同时断言“Insert command”标题的 12px 字号和精确内边距。
- 运行格式化、静态分析和完整 Flutter 测试套件。
